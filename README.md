# Java Dynamic Programming Practice

A collection of Java exercises organized by day, covering recursion, memoization, tabulation, space optimization, and common dynamic-programming problems.

## Getting Started

Install a JDK with `javac`. Compile and run an individual class from the repository root, for example:

```bash
javac -d out "day 2/ClimbingStairs.java"
java -cp out ClimbingStairs
```

Each exercise is a standalone source file; there is no shared build configuration.
